# Items `cargo xtask lint-custom`'s `check-public-audience` lets be public although
# the three audience rules (CLAUDE.md §2) would not, or although they carry no
# Java marker to check.
#
# One entry per line: `<key>  # <reason>`; the reason is required. A key is a
# Rust path (`crate::<module>::<Name>`, the file module dropped or not), a Java
# class (`org.apache.kafka.<pkg>.<Class>`) or a C symbol prefix
# (`kafka_<pkg>_<Class>`); `*` matches any run of characters. An entry that no
# longer lets anything through is reported as stale.

# --- Java classes outside `@InterfaceAudience.Public` that are public anyway ---

crate::admin::MockAdminClient  # Java ships it in the clients test jar for users to test against, as MockProducer / MockConsumer are public
org.apache.kafka.clients.admin.MockAdminClient  # the C binding of the test-jar MockAdminClient above
crate::common::header::internals::RecordHeader  # the only `Header` implementation; users build one to attach headers to a ProducerRecord, as Java users do despite the internals package
crate::common::header::internals::RecordHeaders  # the only `Headers` implementation, returned by ConsumerRecord / ProducerRecord `headers()`
crate::consumer::*ConsumerHandle  # Rust-only: a listener reenters the consumer through it (consumer-threading.md §31, §41), as a Java listener captures the consumer

crate::common::metric::MetricValue  # the value `Metric::metric_value` returns, replacing Java's `Object`

crate::common::metrics::TimeUnit  # translates the JDK's java.util.concurrent.TimeUnit, outside Kafka's audience rules; the public MetricConfig::set_time_window, Rate and Meter take it
