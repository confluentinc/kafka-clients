# @confluentinc/kafka-javascript-linux-x64-gnu

The linux-x64-gnu native binary of `@confluentinc/kafka-javascript`, for Linux x64 with glibc 2.28 or newer: the
Node-API addon with the Confluent Kafka Rust client linked in. Install
`@confluentinc/kafka-javascript` instead: npm installs this package with it, on
linux-x64-gnu, as one of its optional dependencies.
