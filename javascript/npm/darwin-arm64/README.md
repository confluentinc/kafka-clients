# @confluentinc/kafka-javascript-darwin-arm64

The darwin-arm64 native binary of `@confluentinc/kafka-javascript`, for macOS 11 or newer on Apple silicon: the
Node-API addon with the Confluent Kafka Rust client linked in. Install
`@confluentinc/kafka-javascript` instead: npm installs this package with it, on
darwin-arm64, as one of its optional dependencies.
